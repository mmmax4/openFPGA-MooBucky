# Contributing

Keep changes focused and preserve Moo compatibility. Describe the affected
game/revision, behavior before/after and meaningful verification performed.
Do not add ROMs, saves, captured memory states, build directories or secrets.
Retain third-party copyright and license notices.

Use the existing source/build layout; coordinate RTL edits and run one Quartus
flow. Reuse established tests for unchanged dependencies. Physical gameplay
claims require a real Pocket observation tied to the tested bitstream.
Public contributions and releases are held until `LICENSING.md` is resolved.
